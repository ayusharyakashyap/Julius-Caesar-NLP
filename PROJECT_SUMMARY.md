## Key Features Implemented

### ✅ Phase 1: Data ETL & Chunking
- **Robust PDF Extraction**: Uses pdfplumber for handling complex table layouts
- **Intelligent Cleaning**: Removes Folger artifacts (FTLN numbers, headers, footers)
- **Logical Chunking**: Scene-based and speech-based chunking (NOT naive fixed-size)
- **Rich Metadata**: Each chunk has act, scene, speaker, type (dialogue/soliloquy/stage_direction)

### ✅ Phase 2: Indexing & Vector Store
- **State-of-the-art Embeddings**: BAAI/bge-base-en-v1.5 (768-dim)
- **Persistent Vector Store**: ChromaDB with metadata filtering
- **Efficient Retrieval**: Fast semantic search with similarity scoring

### ✅ Phase 3: RAG API Backend
- **FastAPI Framework**: Modern, fast, auto-documented
- **RESTful Endpoints**:
  - `POST /query` - Main RAG endpoint
  - `GET /health` - Health check
  - `GET /stats` - Database statistics
  - `POST /search` - Retrieval-only (for debugging)
- **Proper Error Handling**: Validated requests, meaningful errors
- **Auto-generated Docs**: Swagger UI at `/docs`

### ✅ Phase 4: Prompt Engineering
- **Expert Persona**: Shakespearean Scholar for ICSE Class 10 students
- **Structured Prompts**: System prompt with clear constraints
- **Citation Integration**: Automatic source attribution
- **Gemini 2.0 Flash**: High-quality generation with good reasoning

### ✅ Phase 5: Containerization
- **Docker Compose**: Single-command deployment (`docker-compose up`)
- **Multi-service Architecture**:
  - FastAPI backend service
  - ChromaDB service
  - Streamlit frontend service
- **Volume Mounting**: Data persistence and hot-reloading

### ✅ Phase 6: Evaluation Framework
- **Comprehensive Testbed**: 35 questions (25 factual + 10 analytical)
- **Analytical Questions**: Custom additions for deeper assessment
- **RAGAs Integration**: Faithfulness, Answer Relevancy, Context Precision
- **Automated Reporting**: Generates EVALUATION.md with metrics

### ✅ Phase 7: Frontend UI
- **Interactive Streamlit App**: Clean, intuitive interface
- **Real-time Querying**: Call API and display results
- **Source Visualization**: Show retrieved chunks with metadata
- **Query History**: Track previous questions
- **Sample Questions**: Quick-start templates

1. **Get Gemini API Key**:

## Key Design Decisions to Highlight

1. **Scene-based Chunking**: Preserves dramatic context vs. naive fixed-size
2. **BGE Embeddings**: Better literary understanding than basic models
3. **Gemini API**: Quality/simplicity tradeoff vs. local Ollama
4. **Metadata Enrichment**: Enables precise citation and filtering
5. **API-first Architecture**: Clean separation of concerns

## Common Issues & Solutions

### "API Key Not Found"
```bash
# Check .env file exists and has:
GOOGLE_API_KEY=your_actual_key
```

### "PDF Not Found"
```bash
# Place julius-caesar.pdf in data/ directory
ls data/julius-caesar.pdf  # Should exist
```

### "ChromaDB Empty"
```bash
# Run indexing:
python src/A2_indexing.py
```

### "Port Already in Use"
```bash
# Kill existing process:
lsof -ti:8000 | xargs kill -9
```
